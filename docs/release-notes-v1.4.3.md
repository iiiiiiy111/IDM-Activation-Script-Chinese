# v1.4.3 发布说明 — 版本提示说清楚，扩展报错有排查路径

- 发布日期：2026-08-01
- 类型：文案 / 可用性改进 + 文档补充（**激活 / 冻结 / 重置 / 更新开关的逻辑一行未动**）
- 上一版：[v1.4.2](./release-notes-v1.4.2.md)（上线前稳定性与可维护性补强）
- 对应反馈：[issue #22](https://github.com/tytsxai/IDM-Activation-Script-Chinese/issues/22)、[issue #23](https://github.com/tytsxai/IDM-Activation-Script-Chinese/issues/23)

## 一句话总结

主菜单不再说"支持最新版 IDM"这种会误导人的话，改成把**脚本适配到哪一版**和**你机器上装的是哪一版**都摆出来；同时补上浏览器扩展灰色报错的排查文档。

## 改了什么

### 1. 主菜单显示明确版本号（issue #22）

原来主菜单第一行是：

```
                此脚本可支持最新版本的 IDM。
```

IDM 官方更新很频繁，脚本未必同步。用户看到这句话，会以为当天刚发布的版本也已经适配，激活失败后才发现不是。反馈者的建议很直接：把"最新版本"换成具体版本号。

现在改成：

```
                脚本 1.4.3 | 已适配 IDM 6.43 及之前的 6.x 版本
                本机检测到的 IDM：6.43.3.3
```

- **已适配版本**由 `IAS.cmd` 头部新增的 `idmsupport` 变量单点维护（紧挨着 `iasver`），发版时两个一起更新，不会再散落在文案里；
- **本机版本**在进菜单前读一次 `IDMan.exe` 的文件版本信息（`Get-Item ... .VersionInfo`），**只读，不写任何注册表**；
- 两者主次版本不一致时，多打一行提示指向 README 常见问题 Q10——**这是提示，不是拦截**，IDM 6.x 之间差异通常很小，可以照常尝试；
- 本机没装 IDM 时，这一行显示"本机未检测到 IDM，请先安装 IDM 再激活"。

`开始激活.cmd` 的环境自检里也补了一行 IDM 版本号，自查和提 Issue 时都能直接看到，不用再去 IDM 的"关于"里翻。读不到版本只提示一行，不计入问题数，也不影响激活。

### 2. 常见问题新增 Q16：浏览器扩展灰色报错（issue #23）

有用户反馈 Edge 里的 IDM 扩展图标变灰、右下角带红叉，不能识别可下载文件。这是 **IDM 自身的浏览器集成**（IDM Integration Module 扩展 ↔ 本机 IDM 程序）没连上，不是激活脚本的功能范围——脚本只把 `AdvIntDriverEnabled2` 写回 `1`（打开 IDM 的高级浏览器集成开关），不安装、不更新、也不禁用任何扩展。

README 新增的 Q16 给出按顺序排查的路径：

1. 先确认 IDM 正在运行——激活 / 冻结 / 重置的最后一步会结束 `IDMan.exe`，脚本跑完 IDM 是关着的；
2. 确认扩展与 IDM 版本匹配——商店里的扩展会自动更新，比本机 IDM 新就会报错；
3. 确认 IDM → 选项 → 常规 里对应浏览器的集成是勾上的，改完要完全退出浏览器；
4. 确认 IDM 没有被判"假序列号"（会限制自身功能，扩展跟着报错），必要时按 Q13 用 `[3]` 重置 + `[1]` 冻结；
5. 确认装 IDM 的 Windows 账户和用扩展的是同一个（集成信息在 `HKCU` 下）；
6. 都排除仍报错，属 IDM 自身集成问题，通常重装 IDM 可修复；来仓库反馈请附**扩展报错原文**、IDM 版本、浏览器与扩展版本。

## 维护侧：CI 补上主菜单冒烟

交互菜单是绝大多数用户唯一会看到的界面，此前 CI 冒烟只覆盖 `/silent` 系列的无人值守路径，菜单本身**一次都没被跑过**。这一版的改动恰好落在菜单里，所以顺手把守卫补上：

- 用 `echo 0| call IAS.cmd -qedit` 跑一次交互菜单（`-qedit` 跳过 QuickEdit 的 conhost 重入，管道喂 `0` 让菜单选"退出"），把输出留档；
- 再用 pwsh 按 GBK 解码断言：版本提示行确实打印、runner 上走"未检测到 IDM"分支、输出里没有"此时不应有 / 命令语法不正确 / 系统找不到指定的批处理标签"这类批处理语法错误。

## 没改什么

- 激活 / 冻结 / 重置 / 禁用更新 / 恢复更新的逻辑**一行未动**，行为与 v1.4.2 完全一致；
- 菜单编号、命令行参数、退出码语义都不变，只是菜单顶部多了 1～2 行版本信息；
- GBK 编码、CRLF 行尾、文件末尾空行等约束不变。

## 升级建议

- 想知道"脚本到底适配到哪一版"的用户建议升级，其余用户按需；
- 已经正常激活的机器不需要重跑，本版没有触碰任何激活逻辑。

校验命令（PowerShell）：

```powershell
Get-FileHash .\IDM-Activation-Script.zip -Algorithm SHA256
```

与 `IDM-Activation-Script.zip.sha256` 内的值比对一致后再解压使用。
